# facusenn.github.io

Mi página personal y portfolio: https://facusenn.github.io

Sitio estático (HTML + CSS + JS), sin paso de build. GitHub Pages lo publica directo desde la rama `main`.

## Editar

- **Proyectos:** `assets/projects.js` — cada proyecto es un bloque con título, año, descripción, tags y opcionalmente `image` y `link`.
- **Textos (inicio, sobre mí, contacto):** `index.html`.
- **Estilos y colores:** `assets/style.css` (variables al principio del archivo).

## Ver localmente

```bash
python -m http.server 8000
```

y abrir http://localhost:8000
